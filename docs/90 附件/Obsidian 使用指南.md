## 一、核心概念

### 1. 保险库（Vault）
Obsidian 的全部数据就是**一个文件夹**——这就是"保险库"。你的保险库在：

### 2. Markdown 语法（必须先会这 5 个）
Obsidian 笔记是 Markdown 格式，最常用的是：

```markdown

### 3. 双链（核心中的核心）
用 `笔记名` 就能链接到另一篇笔记：
```

点击链接跳到那篇笔记，而且每篇笔记底部会自动显示"反向链接"（谁链接到了它）。**双链是 Obsidian 区别于普通文件夹管理的根本**——它让你构建知识网络，而不是堆文件。

## 二、日常使用流程

Obsidian 官方推荐的 **PARA-收件箱工作流**，你的文件夹结构已经为此建好：

```
00 收件箱/   ← 新想法先扔这，别管分类
10 知识/     ← 学习笔记、知识卡片（整理后放这）
20 项目/     ← 每个项目一个文件夹
30 日记/     ← 每日笔记
90 附件/     ← 图片、PDF、模板
```

**三步工作流：**
1. **收集**：有新想法，`Cmd+N` 随手记在 `00 收件箱`
2. **整理**：定期（比如每周）把收件箱内容归类到知识/项目文件夹
3. **链接**：用 `双链` 把相关笔记串起来，形成网络

## 五、进阶：让知识形成网络

Obsidian 的强大在于**网状结构**。给你一个实战练习：

1. 在 `00 收件箱` 新建笔记，记下今天学的一个知识点
2. 在正文里写 `[[`，选择一篇相关笔记链接过去
3. 回到 `首页.md`，`Cmd+G` 打开关系图，观察节点如何相连
4. 把收件箱笔记移入 `10 知识`，用 `#标签` 打上分类

坚持"每篇新笔记至少链接一篇旧笔记"，一个月后你的关系图会变成一张真正的知识网。

## 六、发布到公开网站

你的笔记可以通过 MkDocs 发布到公开网站：**https://mart-123-stack.github.io/my-docs/**

**工作流**（写完想公开的笔记后）：
```bash
cd ~/my-docs && ./publish.sh
```
这条命令会把白名单里的笔记同步 + 转换双链 + 推送到 GitHub，CI 自动部署。

**要点**：
- 目前只公开 `10 知识/Obsidian 使用指南.md` 一篇（试点）
- 想加更多：编辑 `~/my-docs/sync_vault.py` 的 `PUBLIC_FILES` 列表
- **隐私保护**：日记、收件箱、项目永远不会同步到公开网站
- 笔记 frontmatter 加 `private: true` 或 `publish: false` 可强制跳过同步

## 七、遇到问题怎么办
