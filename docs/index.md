## 写作指南

直接在 `docs/` 目录下新建 `.md` 文件，并在 `mkdocs.yml` 的 `nav` 中登记即可新增页面。

常用语法：

```markdown
!!! tip "小贴士"
    这是一条提示框

!!! warning "注意"
    这是一条警告框
```

| 功能 | 语法 |
|------|------|
| 标题 | `## 二级标题` |
| 加粗 | `**文字**` |
| 链接 | `[文字](https://example.com)` |
| 代码 | 反引号包裹 |
