### 3. 双链（核心中的核心）
用 `笔记名` 就能链接到另一篇笔记：

点击链接跳到那篇笔记，而且每篇笔记底部会自动显示"反向链接"（谁链接到了它）。**双链是 Obsidian 区别于普通文件夹管理的根本**——它让你构建知识网络，而不是堆文件。

## 二、日常使用流程

Obsidian 官方推荐的 **PARA-收件箱工作流**，你的文件夹结构已经为此建好：

```
00 收件箱/   ← 新想法先扔这，别管分类
10 知识/     ← 学习笔记、知识卡片（整理后放这）
20 项目/     ← 每个项目一个文件夹
30 日记/     ← 每日笔记
90 附件/     ← 图片、PDF、模板
```

**三步工作流：**
1. **收集**：有新想法，`Cmd+N` 随手记在 `00 收件箱`
2. **整理**：定期（比如每周）把收件箱内容归类到知识/项目文件夹
3. **链接**：用 `双链` 把相关笔记串起来，形成网络

## 四、你的 7 个插件怎么用

### 🛡️ Obsidian Git —— 自动备份（最安全的一环）
- 已配置为**每 10 分钟自动备份**一次，全程后台运行，无需操作
- 想手动备份：`Cmd+P` → 输入 "Git" → 选 `Obsidian Git: Create backup`
- 想查看历史：左侧边栏打开"源代码管理"面板，能看到所有提交记录
- **误删文件找回**：`Cmd+P` → "Git" → `Obsidian Git: Open file on GitHub/for Git` → 查看历史版本

### 📋 Templater —— 模板引擎
你已有 3 个模板在 `90 附件/Templates/`：
- `每日笔记.md` — 每天一篇，自动填日期
- `项目.md` — 项目跟踪
- `学习笔记.md` — 课堂/自学记录

**使用方法**：
1. 新建一篇笔记（`Cmd+N`）
2. `Cmd+P` → 输入 "Templater" → `Templater: 插入模板`
3. 选一个模板，占位符会提示你填内容

**更顺滑的用法**：新建学习笔记时，直接在 `10 知识` 文件夹右键 → 新建笔记 → 插入模板，日期自动生成。

### ✅ Tasks —— 任务管理
在任何笔记里用 `- [ ]` 写下任务，然后：
- 用 Tasks 插件可以给任务加**日期**、**优先级**、**重复**
- 所有任务会在首页的"待办事项"里自动汇总
- 示例：
```
- [ ] 读第三章 📅 2026-08-15 🔺
- [ ] 复习周一的课 🔁 每周一
```

### 📌 Kanban —— 看板

### 📅 Calendar —— 日历视图
左侧边栏会多一个日历。**点击今天的日期** → 自动用每日模板创建今天的日记。
日记都存放在 `30 日记/` 文件夹。

### ✏️ Excalidraw —— 手绘白板

`Cmd+P` → 搜 "Excalidraw" → 新建画板。
画完可以**内嵌到笔记里**（``画板文件``），和笔记形成整体。

## 五、进阶：让知识形成网络

Obsidian 的强大在于**网状结构**。给你一个实战练习：

1. 在 `00 收件箱` 新建笔记，记下今天学的一个知识点
2. 在正文里写 `[[`，选择一篇相关笔记链接过去
3. 回到 `首页.md`，`Cmd+G` 打开关系图，观察节点如何相连
4. 把收件箱笔记移入 `10 知识`，用 `#标签` 打上分类

坚持"每篇新笔记至少链接一篇旧笔记"，一个月后你的关系图会变成一张真正的知识网。

## 六、遇到问题怎么办

- **插件报错/主题异常**：`设置（Cmd+,）→ 社区插件` 里可单独禁用排查
- **不小心删了文件**：不要慌，`Cmd+P` → "Git" → 从 git 历史恢复
- **界面乱了**：`设置 → 布局` 可以重置
- **更多帮助**：官方文档 https://help.obsidian.md （支持中文）
